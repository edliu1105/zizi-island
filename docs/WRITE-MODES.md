# 字字岛 · 写字的七种写法（WRITE-MODES）

委托方 2026-10-18：字字岛的写字太单调，永远是"描一个新字，从第一笔描到最后一笔"。点点岛花样很多，字字岛没有。要**用孩子已经认识的字来教新字**，让他看见字和字之间的联系，记得牢。例子：

- 先写好"人"，他加一横，就知道这是"大"；"大"加一点是"太"；
- 日 / 木 / 月 / 目：先写好"日"，他加一笔就成了"目"。

写字要灵活、多变，不无聊，每个字从最合适的角度来教。所有世界都一样，以后的世界也一样。

## 1. 七种写法

所有写字题都走同一个入口：每个岛的写字、写字母、老朋友、复习题、字宝盒里的重写、教一教。每道题用下面一种写法。

| 写法 | 他做什么 | 毛笔做什么 | 说的话（≤ 8 字） |
|---|---|---|---|
| **描**（trace） | 整个字一笔一笔描（提示按级别：L1 毛笔先写一遍，有绿点、箭头、底字……L5 空格） | 第一次、L1 时先写一遍 | 字的那句话 |
| **加一笔变新字**（grow） | 只写新加的那一两笔，而且在笔顺里**它该出现的时候**写 | 认识的那部分，**轮到哪一笔写哪一笔** | 人加一横变成大！ |
| **部件拼字**（part） | 写另一个部件 | 写他认识的那个部件，也是轮到时才写 | 日加月变成明！ |
| **像不像**（look） | 写问的那个字（旁边两张卡：日、目） | — | 写完：目比日多一横 |
| **补缺笔**（fill） | 写缺的那一笔（L4 起缺两笔） | 写其余的笔，轮到时写 | 少了一笔！ / 少了两笔！ |
| **接龙**（relay） | 写第 1、3、5……笔 | 写第 2、4、6……笔 | 你一笔，我一笔！ |
| **描仿写**（fade） | 同一个字写三遍：描（底字、绿点、箭头）→ 只有起笔绿点 → 只给第一笔的绿点、凭记忆写 | — | 描一描！ 照着写！ 自己写！ |

### 1.1 加一笔变新字（这次最主要的写法）

1. 纸上出现他认识的字，比如"人"，用的是"人"自己的字形，黑墨。
2. "人"滑到它在"大"里的位置，大小也跟着变（人的撇捺就是大的撇捺）。
3. 新加的那一笔亮起来（橙色，闪两下），配音："人加一横变成大！"这就是"啊哈"的那一下。
4. 然后纸变成他的：认识的部分变成浅色的影子，他按笔顺写。

**笔顺不能乱**（GF 0023-2020）："大"是先横后撇捺。所以他先写横，接着毛笔写人的撇和捺。"日"变"目"：毛笔写竖、横折、中横，他写新的那一横（目的第 4 笔），毛笔再写最后一横。新的笔在笔顺中间时，前面的笔由毛笔先写，后面的笔由毛笔接着写完。整个字的书写顺序始终是标准笔顺；如果他先写了后面的笔（不管是他的还是毛笔的），都不收，提示"先写这一笔"。

新加的笔是什么，由他的级别决定怎么提示：L1–2 有绿点、橙色笔画（L1 还有箭头）；L3 只有橙色笔画；L4 很淡；L5 只有影子，凭记忆写。开头那一下"亮起来"每一级都有，因为这正是要教的。

**第一次见到一个字**仍然是描（下面第 2 节）。如果他认识的字能变成它，描之前先演一遍这个"啊哈"（"大加一横变成天！"），再"看我写一遍"。所以新字一出场，就和老字连在一起。

### 1.2 部件拼字

和 1.1 一样，只是认识的是一个部件：日 + 月 = 明。日从它自己的样子缩进明的左边，月亮起来（L4 起不亮，凭记忆），配音"日加月变成明！"。日在前，毛笔先写日，他写月。如果他认识的是月，他先写日，毛笔再写月。只用两个部件都是 app 里教的字（第 3 节的表）。

### 1.3 像不像

两张卡并排：日、目（小的在前，问的那张是金框）。他写问的那个。写完，大的那张卡上多出来的笔亮成橙色，配音"目比日多一横"。字对只用加一笔的家族（第 3 节），两个字都要是他**亲手写过的**（写字记录里有），只认识、只读过的字（比如只认不写的三、王、出）不会出现在卡上（W4R2-06）。

### 1.4 补缺笔

字的影子少了一笔（L4 起少两笔，如果字有 4 笔以上），他把缺的写上。提示：L1 橙色笔画、绿点、箭头；L2 只有绿点；L3 起只有空缺本身。写错时和平时一样，出现绿点和箭头。其余的笔由毛笔在轮到时写，所以笔顺还是对的。

### 1.5 接龙

"你一笔，我一笔！"他写第 1、3、5……笔，毛笔写第 2、4……笔。3 笔以上的字才用。他必须知道每次轮到的是哪一笔。

### 1.6 描仿写

同一个字三遍，在同一张田字格上（每遍写完墨迹淡去）：
1. "描一描！"：底字、绿点、箭头。
2. "照着写！"：没有底字，只有每一笔起笔处带编号的绿点。
3. "自己写！"：只有第一笔的绿点。

2–8 笔的字才用（字母 2–4 笔）。三遍都没写错才算一题全对。

## 2. 什么时候用哪一种（轮换）

- **第一次写一个字**（还没写对过）：描。之前先演"啊哈"（如果他认识的字能变成它，或者能拼成它）。
- **写字的保底**（连续三题没拿到星，进入描红级）：描。
- **以后每次**（复习、老朋友、岛上再写、字宝盒重写、教一教）：在这个字**能用的写法**里，选**最久没用过的那一种**。同一局里，不和上一题用同一种（如果还有别的可选）。
  - 能用的写法：描总可以；有认识的"加一笔"老字 → 加一笔变新字；有认识的部件 → 部件拼字；家族里另一个字也亲手写过 → 像不像；3 笔以上 → 补缺笔、接龙；2–8 笔 → 描仿写。
  - 用过的记录存在这台设备上（`zzi.wm`，每个字记最近 7 次），不进存档。
- 所以一个学过的字会把它所有的写法轮一遍，才会重复；老字也会以"加一笔""拼字""像不像"的样子回来。哪个字到期复习，仍然由原来的记忆系统（7 个箱子）决定，写法只决定"怎么写"。
- **星星**照旧：只有第一次就全对（所有轮到他的笔都没写错，描仿写三遍都没写错）才有星。写错时照旧讲解（金圈；"再看一看""看，是这样"，毛笔把写错的那一笔重写一遍；一步一步模式一样）。没有"错"字、红叉、失败音。

### 字母

字母用描、补缺笔（2 笔以上）、接龙（3 笔以上）、描仿写（2–4 笔）。字母之间没有"加一笔变新字"：唯一字面成立的是 F → E，但两者笔形太像，b / d / p / q 又是镜像而不是加笔，所以不做（这样更不容易混）。

## 3. 字的家族表（附录）

**从数据来，不靠手**：表在 `tools/content.py` 的 `STROKE_FAMILIES` 里（神笔海 ⑨ 的"加一笔"挑战也用这一张表）。每一对都由 `tools/write_pairs.py` 拿笔画数据来证明：

- **加一笔**（A → B）：B 比 A 多 1 到 2 笔；A 的每一笔都在 B 里，**按 A 的顺序**，**笔名相同**（STROKE_NAMES），**形状相同**（A 和 B 的这几笔各自放进单位方框，每一笔取起点、四分之一、中点、四分之三、终点五个点比较：平均 ≤ 16，最差 ≤ 26，单位是方框的百分之一）。
- **部件**（B = A + C）：B 的前几笔就是 A，后几笔就是 C，每一块都在自己的方框里和那个字比较（偏旁会被挤窄：平均 ≤ 22，最差 ≤ 30）。左边、上边的部件可以把最后的捺写成点、横写成提（木在林里、女在好里），这也是标准的写法。

表里的字还没进 app（还没有笔画数据）的，先等着（"pending"），哪天进来哪天检查。检查不过的不进 app（构建时只警告、跳过），`tests/test_writemodes.py` 会失败。

**小 → 少 不算**：小的第一笔是竖钩，少的第一笔是竖（钩没了），不是"小加笔画"。大 → 太、十 → 干、日 → 旧 等等，因为太、干、旧不是 app 里教的字，现在不用；以后教了，加进表里就自动检查。

## 4. 哪里都能用

- **每个世界的每个岛**：写字（晨光海、星光海、彩虹海、神笔海）、写字母、句子岛的老字母。都走 `WriteBase.present`（`src/games.js`），彩虹海、神笔海的 `W3Write` / `W4X.Write` 只决定写哪个字（老朋友），写法照样轮换。
- **字宝盒重写**（练字）：学过的字，照样轮换，提示是 L1 的（全有）。
- **写字保底**：描红级（描）和读的那一步都不变。
- **教一教**：写法照样轮换，按降低后的级别给提示；什么都不记（原规则）。
- **一步一步讲解**：写错的那一笔照旧"再看一看"、"看，是这样"（只会是他写的笔）。
- **复习 / 记忆系统**：到期的字仍由 7 个箱子决定；复习题、老朋友也按这里的规则轮换写法。

## 5. 技术

- `src/writer.js`（首屏）：`Writer` 新增 `given`（毛笔写的笔，轮到时用墨写）、`ghost`（这些笔的浅色影子）、`cues`（不按级别时给哪些提示：底字、橙色、绿点（这一笔 / 全部 / 只第一笔）、箭头）。判断不变：只收这一笔，顺序、方向、起点照旧。还有一个小小的懒加载 `WM.load()`。
- `src/wm.js` → `assets/js/wm.js`（第一次写字时才加载，约 6 KB gzip）：选写法、演"啊哈"（字形滑进新字的位置）、卡片、补缺、接龙、三遍写。家族表由 `tools/build.py` 从 `write_pairs.families()` 放进去。没加载到（离线、还没缓存过）就全用描。
- 首屏只多了约 1.6 KB gzip。
- 声音：`tools/voice_lines.py` 收集（家族的句子来自 `write_pairs.lines()`，`wm.js` 里的句子靠扫描），`tools/voice_bank.py` 录（Edge TTS，晓伊）。
- 测试：`tests/test_writemodes.py`（家族表是真的、app 里带的就是这张表、每种写法用真鼠标在三种屏幕大小上写完、写错顺序不收、轮换、字宝盒 / 教一教 / 复习 / 一步一步、截图在 `tests/logs/writemodes/`）。
