# 字字岛 v2 · 对第 3 轮评审（V2R3，9/10 · APPROVE，最后一轮）的回应

评审通过。交付前把剩下的 7 条都处理了，验收在 `tests/test_v2r3.py`（7/7）。这批修改没有再送评审，只有自测。

- **01 "是"过关了却一直灰着、锁着**（上一轮把它改成只认读带出来的）→
  - `learned(k)` 对只认读的字（`NOWRITE`）改用"已过关"：两局里自己认对就算学会。
  - 字宝盒点亮，封面和家长面板也数它；其他字仍然要写过。
- **02 写字兜底第二级晚一个字生效** → 兜底升到第二级的那一刻，这一轮就结束，下一轮直接是认读卡或描红练习，不用先写下来一个。
- **03 钥匙题缩到 3 道要等家长开面板** → 判断搬进 `Keys.start()`：三天里中途退出两次，下一次钥匙局自动 3 道。面板只显示。
- **04 三个漏答挤占下一局** → 最多带 2 个，排在第 2、4 题。
- **05 首次开地图时"找回老朋友！"插在翻卡和开岛之间** → 还有旗要插、岛要开时，这一次不说，下一次进地图再说。
- **06 钥匙局可能一半以上是字母** → 先取到期的汉字（最逾期的先），不够再补字母。
- **07 小地方** →
  - 考一考的"结束"改成和其他按钮一样大（88 px）；
  - 一局结束时如果同时要说"再玩一局插旗子！"和问"停船还是继续？"，先说前者；
  - 报告的"版本"一栏用页面的发布时间。
