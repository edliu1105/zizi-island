# 用户体验评审（R1，Fable 5.1 · high）

你是独立评审。对象是 `index.html`（字字岛）：给 4 岁中文孩子的 iPad 认字、写字、学字母 PWA。设计说明见 `docs/DESIGN.md`，请先读。

## 委托方的原话要求（请检验做得好不好）

1. **内容**：做一个写字岛 / 认字岛。主题是常用物体、常用东西，学写它们的中文字和英文字，从生活中最常用的教材和最常用的东西开始。普通话和英文的基本认字、写字都在这个 app 里。
2. **形式**：设计思路跟点点岛（同一委托方的数学 app）一样。要是一套很好的、很适合小孩子直观学习写字和读音的 app，让孩子能认、能写一些简单的英文和中文字。可以加入奥特曼系列、变形金刚系列。
3. **素材**：如果用关卡制，要专门生成每一关的环境背景、游戏素材和所有需要的素材，不要只用 SVG 这类低质量素材，要用 Codex 生成高质量素材和人物素材。
4. **规模**：至少一到两个世界，难度逐步递进。
5. **练习与解锁**：要有一直能练的字，有和点点岛类似的解锁机制和语音。
6. **进度看得见**：完成后奖励星星、插旗子，然后才能解锁下面的关、下面的岛屿、下面的世界。
7. **形式不是死的**：如果有比"世界 → 小关 → 小游戏"更好的形式也可以用，但必须有明显的进度、奖励、逐步解锁和成就感，直观、好玩，同时让孩子学到文字的读、写、认。
8. **标准**：年度 App Store 年度 App、时代周刊年度推荐 App 的水准。

## 沿用点点岛的铁则

- 星星只给孩子自己第一次就做对的题；写字要每一笔都写对。
- 答错时就事论事说一句，换一道新题，不显示答案，不说"你错了"，没有失败音和红叉。
- 卡住时只能语音鼓励、重说题目、示范"怎么做"（写字示范这一笔），永远不替孩子做。
- 语音每句不超过 8 个字；点按目标不小于 88 px；家长功能藏在"长按齿轮"后面。

## 评审方式

从孩子和家长的体验出发评审，约 60 分钟。评的是孩子和家长看到、听到、摸到的东西；代码只在发现问题时用来找原因。截图必须亲眼看。横屏 1180×820 和竖屏 820×1180 都要看。

## 重点

1. **写字**是这个 app 的核心（田字格写汉字、四线三格写字母）。请检查以下几点：
   - 一个 4 岁孩子看得懂吗：绿点、数字、箭头、毛笔示范。
   - 写得出来吗：手指不准时能不能过，写反、写错笔顺能不能发现。
   - 判断说的话对不对。
   - 笔顺和笔画名对不对。
   - "字活过来"的那一刻好不好。
2. **认字的 14 种玩法**和 **14 种推理挑战**，每个岛至少抽 2 个：
   - 任务能不能看懂：孩子不识字，靠语音和图。
   - 第一次见到一个字时的"字从画里来"。
   - 答对后的揭晓、答错后的那句话。
   - 难度递进合不合适。
   - 玩法之间有没有其实重复的。
3. **进度和成就感**：星槽、5 颗星、岛面板（4 个游戏 + 5 颗小星 + 这个岛的字）、地图上的旗子、新岛开放、第一世界插满七面旗后的庆典和大结局、门变金后去第二世界。另外看字宝盒：学会的字变彩色、练字加小红花、3 朵金边，以及随时练字。
4. **语音**：
   - 中文、英文读音是否准确清楚：字母名、单词，例如 "A, apple!"。
   - 句子有没有被吞掉：真实时长下，开场、题目、提示都说到了。
   - 有没有没录音的句子：`window.__vmiss`。
5. **铁则**：故意不操作 60 秒，确认没有任何替孩子做的动作。故意答错几次，确认换新题、不给星。
6. **视觉问题**：被挡住、裁切、重叠、错位、看不清、字太小。
7. **新角色**：奥特曼、赛罗、擎天柱、大黄蜂（Codex 生成）和委托方原有的角色放在一起是否协调。

## 工具

本目录已装好 Python + Playwright。Windows 控制台先设 `PYTHONIOENCODING=utf-8`。

- **`tests/harness.py`**：
  - 主要函数：`serve()`、`new_page(browser, base, vw, vh, fast=True|False, hint_scale=...)`、`enter(page)`、`wait_phase()`、`step(page, 'right'|'wrong')`、`q(page)`。
  - **进游戏**：`window.__go(island, game, level, {seed})`，不检查锁。
  - **岛**：`peppa bluey huluwa paw xiyou ultra robot`（第一世界），`peppa2 bluey2 pj ultra2 huluwa2 xiyou2 robot2`（第二世界）。
  - **小游戏**：`<岛>:find`、`<岛>:write`、`<岛>:abc`、`<岛>:quiz`；level 为 1–5。
  - **状态和进度**：`window.__q`、`Store`、`Prog`（进度：`stars / gameDone / gameOpen / islandDone / worldDone`）、`MapView`、`Book`、`window.__speechLog`、`window.__vmiss`。
  - **当前写字题**：`Session.st.w`，用 `.expected()` 拿到当前这一笔在舞台上的点。
- **造存档**（改完 `Store.save()` 后刷新）：
  - 某个小游戏的星：`Store.w('peppa').gstars['peppa:find'] = 4`。
  - 第一世界全部过关：`ORDER.w1.forEach(id => { const ws = Store.w(id); ws.unlocked = true; ISL[id].games.forEach(g => ws.gstars[g] = 5); })`。
  - 学会的字：`Store.learn('山')`。
- **已有测试**：
  - `python tests/test_core.py`：每个小游戏 5 颗星、答错换新题、判笔、进度、语音覆盖。
  - `python tests/test_pointer.py`：用真的鼠标轨迹写字。
  - `python tests/test_layout.py`：目标大小、遮挡。
  - `python tests/smoke_local.py "" L|P`：每关截图，输出到 `tests/logs/shots/`。
  - `python tests/shots_screens.py`：地图、岛面板、字宝盒、大结局的截图。
- 可以自己写短小的 Playwright 脚本截图，用 Read 查看。

## 结果

不要修改应用代码。结果用中文写到本目录的 `REVIEW-R1.md`，按顺序包括：

1. 总体结论（2–3 句）。
2. 问题按严重程度排序，格式：`[严重|中等|轻微] 编号 描述（证据：截图/步骤）→ 建议`。
3. 抽查了什么。
4. `SCORE: n/10`。9 分是顶级付费儿童应用（年度 App）的水准；7–8 分是扎实但有"做出来"的痕迹。
5. 最后一行：`VERDICT: APPROVE`（9 分及以上且没有严重问题），否则 `VERDICT: REJECT`。
