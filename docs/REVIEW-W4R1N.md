## 1. 总体结论

神笔海的工程质量很高：七个岛、28 个游戏、21 种新玩法全部跑通，铁则逐条核对没有一条被破坏——星星只给第一次答对、答错不说"错"没有红叉、每题五个选项或一题两问、点按目标三种尺寸都 ≥ 88 px、每句话有录音、笔顺按 GF 0023-2020（左、右先横后撇）、家长功能在齿轮长按后面、没有第三方库。**开启和入口**是这次重点，结果很好：四种存档都能马上找到神笔；神笔在三片海、八种尺寸下都在屏内、在最上层、不挡任何东西；第一次自动飞过去只演一次；月亮门回到来的那片海；旧存档的岛、星、旗、记忆箱、卡一样不少；家长面板有"现在就去神笔海"。只过晨光海的新存档在神笔海里从不见到星光海、彩虹海的字。

但从**4 岁孩子的体验**看有三处中等问题需要修：⑦-1「顺着线找一找」拉线的人里就有"爷"（葫芦爷爷）和"妹"（Bingo）本人，L1 任务卡上画着爷爷、下面站着爷爷却拉着别的风筝，是给 4 岁孩子挖的坑；②-3「谁不是一家」从 L2 起大量使用没教过、没有图的单词（pin tin win bin hit fit pot dot……）；⑦-4「哪句说得通」的四个错项几乎每题都是"牙上 / 米中 / 月上 / 耳中 / 石中"，孩子很快学会"看到牙米月耳就不选"，不读前半句也能答对。另有几处低风险问题（对不对按钮上的 ✓、卷轴灰字太淡、首屏 gzip 只剩 3.3 KB 余量、两个旧测试套件没跟着红点规则改而失败）。

没有任何阻塞上线的缺陷；三处中等问题都是数据或小逻辑改动。按本任务的评分规则（9 分及以上才通过），本轮给 8 分，**不通过**，修完上述三处即可通过。

## 2. 问题（按严重程度）

### 中

**W4R1N-01 · ⑦-1「顺着线找一找」：拉线的人就是"爷"和"妹"的图，L1 直接把孩子引向错答案**
- 证据：`src/w4/bluey4.js:17` `HOLD = ['bluey','bingo','bandit','chilli','grandpa']`，`gen()` 第 56 行 `who: G.rng.shuffle(HOLD)` 与答案无关。而 `tools/content.py:350` 里 爷 的图是 `@grandpa`、妹 的图是 `@bingo`。截图 `tests/logs/rev/g_1180x820_bluey4_find_L1.png`：任务卡画着"女"的小女孩，下面五个人里葫芦爷爷拉着"女"的风筝；`g_1180x820_bluey4_find_L2.png`：爷的风筝连到 Bingo，奶的风筝连到爷爷。
- 为什么是问题：L1 是"任务卡有图"的那一级。问"爷"时任务卡上就是葫芦爷爷的脸，4 岁孩子看到下面站着同一个爷爷，第一反应是点他——这不是在练"顺着线"，是在惩罚他刚学会的"爷 = 爷爷"。答错后讲解说"这是奶"（他点的人拉的风筝）并配奶奶的图，而他点的明明是爷爷，图和话对不上。
- 建议：拉线的人不要用本岛任何一个字的图：换成 Bluey、Bandit、Chilli 加两个和本岛字无关的委托方角色（例如猪爸爸、猪妈妈，`CASTS4`/英雄卡里都有原图）；或至少保证 L1–L2 时葫芦爷爷拉的就是"爷"、Bingo 拉的就是"妹"（题目问到它们时）。

**W4R1N-02 · ②-3「谁不是一家」：L2 起用了约 45 个没教过、没有图的单词**
- 证据：`src/w4/peppa4.js:155` `EASYW = 'big dig hop pop men ten fun run hit sit bit fit hot pot dot not wet pet sad dad bad mad bag tag rag wag lip hip tip zip red fed hug tug pin win tin bin fog hog jog cut hut nut'`，`fams()` 把它们和 `WORDS4`/`WORDS3` 混成词族。实测 L2 出了 `pin tin win net bin`（截图 `g_1180x820_peppa4_en_L2.png`），L4 `pin tin hen win bin`，L5 `hit bit fit net sit / dot pop pot not hot`（`tests/logs/rev/dump_questions.json`）。设计文档 §6 ②-3 写的是 `WORDS4` 里的词（bug rug mug jug + hen）。
- 为什么是问题：孩子只学过 24 + 19 个有图、有音的 CVC 词。pin/tin/win/bin 既没在任何岛出现过，也没有图，点卡只能听到一个他不认识的词；讲解念"pin, bin"对他没有意义。看尾巴找规律这个机制本身可行，但材料应是他见过的词，否则英文线"词族 → 常见词 → 短句"的衔接就断了。录音倒是齐全（`test_w4` 11 两次都 0 缺）。
- 建议：词族只从 `WORDS3 + WORDS4`（都有图）里取；不够凑四个一族的尾巴就不出这个尾巴（-at、-an、-ug、-op、-en、-un、-ox、-og 都够）。L5 两排时允许 -ap、-ig、-et 用三个一族 + 一个外人。

**W4R1N-03 · ⑦-4「哪句说得通」：错项高度重复，可以不读题靠排除法答对**
- 证据：`tools/content.py:526-559` `SENSE4` 30 题里 24 题的四个错项都在 {牙上 / 米上 / 米中 / 月上 / 耳中 / 石中 / 天上} 这七个里打转；实测 L1 `车 | 去米中。去山下。去月上。去牙中。去天上。`、L4 `小鸟飞 | 上牙。上米。上月。下石中。上天。`、L5 两问 `天上。米中。山上。耳中。牙上。 / 站牙上。站月上。站耳中。站山上。站米上。`（`dump_questions.json`、截图 `g_1180x820_bluey4_quiz_L2.png`、`ex_bluey4_quiz_1.png`）。
- 为什么是问题：这是本世界唯一"读整句、判意思"的挑战。第三题起孩子就知道"有牙、米、月、耳的都不对"，只看后半句有没有这几个字就能拿星，前半句根本不用读。对的那句几乎总是"山上 / 地上 / 水中 / 车上 / 上天"，同样可猜。
- 建议：每题至少两个错项用别的"不可能"（鱼 | 吃石头 / 飞上天 / 坐车上；牛 | 飞上天 / 去月上 / 坐伞上），让错项不再是一组固定记号；也让"山上 / 水中"偶尔出现在错项里（马去水中？牛去天上？），迫使孩子读前半句。两字错项的字都在 `ENDPIC4` 里才能拼出好笑的图，这个约束保留。

### 低

**W4R1N-04 · ⑥-3「对不对」：点头按钮上预先带着一个绿色 ✓，看起来像已经选好了**
- 证据：截图 `g_1180x820_paw4_en_L2.png`，两行的"对"按钮右上角都有绿圈 ✓ 徽章，答题前就在。
- 问题：4 岁孩子会以为这题已经答了、或 ✓ 就是"点这里"；而且 ✓ 正是本世界"对"字的图（`check.png`），容易混。按钮本身用点头 / 摇头的小狗已经足够。
- 建议：去掉徽章，或两个按钮都不带徽章，只在选中后出现金圈。

**W4R1N-05 · 儿歌卷 / 古诗卷里"还没学的字"的浅灰太淡**
- 证据：截图 `misc_scroll_r1.png`、`misc_scroll_p2.png`，灰字 `#BDB3A0` 印在米色卷轴上，在 iPad 上家长陪读时不容易看清；《画》四句里孩子认识的字也只有一半，整卷大半是浅灰。
- 建议：改成深一些的灰（约 `#8A8070`），"认识 / 还没学"的区别靠黑和灰的对比就够了。

**W4R1N-06 · 首屏预算只剩 3.3 KB**
- 证据：`index.html` 610,457 字节（预算 640,000）、gzip 176,673（预算 180,000），`tests/logs/rev_w4open.txt` 第 08 条。
- 问题：下一次任何首屏改动（哪怕一段讲解文案）就会把预算打破。`src/w4/boot.js` 里的家长面板文案、`LESSONS4` 18 行表、`CARDS` 新 15 张都不是首屏必须的。
- 建议：把家长面板的神笔海一节和 `LESSONS4` 挪进懒加载的 `w4.js`（面板打开时 `await W4Lazy.ready`），首屏能省约 3–4 KB gzip。

**W4R1N-07 · 两个旧测试套件没跟着红点规则改，`run_all.sh` 发布检查会报 FAIL**
- 证据：`tests/logs/rev_v2.txt` V-12 两条 FAIL（期望 `Supply.low()` 为真、进彩虹海有红点），`tests/logs/rev_w3new.txt` 08 两条 FAIL（同样是红点）。原因是设计 §10.5 把红点改成"剩下没插旗的岛不到 7 个"，代码对（我实测：只剩 2 个岛没插旗时 `Supply.low()` 为真，新存档为假），测试期望没改。
- 建议：更新 `test_v2.py` V-12、`test_w3new.py` 08 的期望值；发布前 `bash tests/run_all.sh` 应是 ALL: PASS。

**W4R1N-08 · ④-4「送字回家」小屋门上的类别图太小、太抽象**
- 证据：截图 `g_1180x820_xiyou4_quiz_L2.png`：五座小屋门上约 60 px 的线描图——脚印 = 动物、火柴人 = 身体、奔跑剪影 = 动作、云 = 天上、山 = 地上。
- 问题：4 岁孩子不一定把"脚印"读成"动物"、把"火柴人"读成"身体"。L1 有字的图、答错后金圈说"这是动物"能补救，但首次见到时没有抓手。
- 建议：门上的图放大到 ≥ 100 px，并换成更直接的（动物：一只小狗的脸；身体：一只手 + 一只眼睛；动作：小男孩跑步的彩图 `run.png`）。

**W4R1N-09 · ④-1「摘桃找词」词表里有几个对 4 岁孩子陌生、也不太像"词"的条目**
- 证据：`tools/content.py:513-519` 有 人口、山口、小人、人心、牛马、对门、听说、不对、对了。L2 起它们可能成为答案（"摘人口！"）。
- 建议：删掉 人口 山口 小人 人心 牛马 对门，保留能画、能解释的。

**W4R1N-10 · 几张英文图的"看图叫得出"有点勉强**
- 证据：`assets/obj/bun.png` 是一个中式包子（英文 bun 一般指面包卷）；`tincan.png` 罐头标签是空白的；两者在 `WORDS4` 里都标了 `clear=1`（可用于不念出来的题）。
- 建议：bun、can 改成 `clear=0`（只在念出来的题里用），或换图。
