# 用户体验评审（字字岛 v2 · 第 3 轮，最后一轮，Fable 5.1 · high）

你是独立评审。对象是 `index.html`（字字岛）：给 4 岁中文孩子的 iPad 认字、写字、学字母 PWA。

**这次评审的是 v2 第一期**，也就是 `docs/PLAN-v2.md`（Opus、Codex、Fable 三方共识的终极方案）里 1a 和 1b 两批的实现。请先读：
- `docs/PLAN-v2.md`：方案；
- `docs/DELIVERY.md` 开头的"v2（第一期）"一节：这次做了什么；
- `docs/DESIGN.md`：v1 的设计。

v1 已经评审过 3 轮（R1 7/10、R2 8/10、R3 9/10，见 `docs/REVIEW-R*.md`）。

## 委托方的要求

- **地图就是课本**：顺序固定，速度归孩子。
  - 孩子靠不断解锁新岛、看到新英雄（奥特曼、变形金刚、复仇者、美国队长、蜘蛛侠、钢铁侠……）驱动。
  - **不能有每日上限，也不能暂停新内容。**
- **效果要达到甚至超过报班**（学而思、悟空中文这类）：系统的课程、按遗忘规律复习、学得牢、看得见。
- **每个世界都要有新的玩法**，同时内容要按教材标准一步步递进。
- **进度看得见**：星星、旗子、解锁。
- 其余和 v1 一样：iPad 上直观、好玩，App Store 年度 App 的水准。

## 铁则（沿用）

- 星星只给孩子自己第一次就做对的题；写字要每一笔都对。第二级提示之后答对不给星（v2 新加）。
- 不代做，不揭晓答案。答错就事论事说一句，换新题，不给星。没有失败音，没有红叉。
- 每句中文语音不超过 8 个字；点按目标不小于 88 px；家长功能藏在长按齿轮里。

## 先验证上一轮
