## 1. 总体结论

彩虹海这一期做得扎实。15 种玩法确实都是新的：代码里每种有自己的规则（找全部副本、按方向甩、颜色会骗人、黑暗里找、先瞄准再射；押韵、补元音、首字母、默读单词、I spy；数一数、点灯做出答案、涂颜色、全家福、照着做），和前两个世界、句子岛的 28 + 8 种都不同，彼此也不同。铁则一条没破：15 种玩法 × 起始级各打两局（全对 → 5 星；第 2 题错 → 4 星、紧接着是一道新题）；答错后说的话只说点到的那个是什么，从不说答案、不说"错"，全部有录音；第二级提示之后答对一律不给星（密码单词是软提示，和读一读同规则）；点"看字卡"听字那题不给星、下一题照常给；1200 道生成题每题只有一个对的答案；点按目标在 3 种尺寸、全部难度下都 ≥ 88 px、在屏内、在最上层；语音新句子都不超过 8 个字且都有录音；家长功能仍在长按齿轮后面。数字图 1–10 个苹果逐张数过都对；颜色图（草莓、香蕉、鲸、恐龙、北极熊）都不是已学的字；读一读新句子的三张图逐一看过，颜色滤镜出来的"错图"颜色对（红车 / 蓝车 / 绿车，蓝鸟 / 红鸟 / 黄鸡，白兔 / 棕兔 / 狗）。进度与记忆在彩虹海正常：星光海玩完只开天宫，旗一面一面开岛；绿巨人山谷四个游戏各一局全对就当场插旗（认字 + 挑战各给每个字一次过关），雷神云岛开，书架不多书，雷神插旗后才有《十本书》；答错的字两题后以卡回来说"再来一个"，一局最后答错的带到下一局第 2 题；新字进第 1 箱、明天到期；到期的老字在砸石头里用本关的框考（"砸碎所有的月！"），挑战里偶数岛第二个复习位是读一读、奇数岛是卡；刹车（当天新字 > 8）时每局 3 道、到期不够不凑数；钥匙局先考汉字、0 星、翻一张卡；红点一进彩虹海就亮；只认读的字两局过关后就"学会"、字宝盒点亮、计入"学会的字"。写字每岛只写 2 个字加第 3 题的老朋友（最到期的那个），一局里不会连着写同一个字，答错后换另一个；写字兜底两级在新岛上照常；家长的"写字不挡开岛"照常。第 7 面旗 → 翻卡 → "庆典开始啦" → 彩虹海自己的大结局（20 位朋友，"彩虹大派对！""一起拍照，茄子！"）→ 彩虹门回晨光海，真实时长 0.3 / 1.8 / 6.0 / 9.5 s，顺序对、没有重叠。既有 12 个套件全绿（v2r1、v2r3 在快照里要读 `src/app.js`，我改成读 `index.html` 后全过）。

但委托方两条明文要求各有一处实打实没做到，还有一条规则在精神上没守住：

- **"同一个游戏 L1–L5 一级比一级难"**：十格灯在实际玩到的 L3、L4、L5 完全一样（出题只分 lv ≥ 3 / < 3，画面和交互不随级变）；补元音 L3 = L4 = L5（都是 5 个元音）。另有押韵 L4 = L5、全家福 L4 = L5、密码单词 L3 = L4。
- **"重复的关卡没有意义"**：岛上只剩一个字没过关时，整局 5 题全考它。十格灯、全家福、照着做连题目都一模一样；数一数、涂颜色、认字换干扰项不换答案。这条路径很常见（第一局认字的第 4、5 题错一个，后面的挑战就是 5 遍同一个字）。前两个世界的认字早就这样（V2R1-02 带来的），这一期把它扩到了挑战，而且十格灯会出现五道一字不差的题。
- **"第二级提示之后答对不给星（只把问题再说一遍的提示不算）"**：15 种里有 8 种（押韵、补元音、首字母、我看见、数一数、涂颜色、全家福、照着做）没有第二级提示的内容——10 秒时只有主持人挥一下手，什么也不说、什么也不出，星却没了。孩子对着"爸爸"想了 10 秒、然后自己点对，拿不到星。前两个世界的 13 个挑战也是这样，但这一期多了 8 个，而且其中 4 个是"看字卡"的阅读题，想一会儿正是题目要的。

其余是小问题：涂颜色的白色颜料桶不好认、《红车白云》的"花是红的"是一朵粉花；特工基地认字图标黑字压深色背景看不见、写字图标红字压晚霞；字宝盒里点亮的只认读字（喝 12 画、蓝 13 画）一点就是整字书写练习；跳石头第一局（L2）就开始颜色骗人；甩锤子时锤子不跟手；"哥 = 大娃"和"来 = 招手"要靠认识角色和领会手势；快照里两个套件依赖 `src/`。

分数 8：核心玩法、铁则、进度、记忆、回归都过硬，但委托方的两条硬规矩（级级变难、不重复）在交付里各有一处明确的漏洞，第二级提示白扣星的范围也扩大了，这三条都值得改一轮再交付。

## 2. 问题（按严重程度）

**[中等] W3R1-01 十格灯 L3–L5 一模一样，补元音 L3–L5 一模一样（委托方："L1–L5 一级比一级难"）**
证据：`rv_data.log`（每级 60 道生成题的统计）：`thor3:quiz` L1、L2 只出本岛的六–十，L3、L4、L5 都是 1–10 均匀各 6 道，`gen` 只判断 `lv >= 3`（`QFrame.gen`），`present` / `place` / `onGesture` / 提示都不看级；而挑战在彩虹海从 L3 起（`ISL.base 2 + boost 1`，`rv_data.log` 的 start levels），所以孩子从第一局到打满星，这个游戏没有任何变化，L1–L2 反而只考 6–10（更难）。`thor3:en`（`EVowel.gen`：`n = lv <= 1 ? 2 : lv === 2 ? 3 : 5`）L2 三个元音、L3–L5 都是五个。较轻的：押韵 `n` 在 L3–L5 都是 4、L4 起同元音（L4 = L5）；全家福 `FAM_Q` 最高 lv 4（L4 = L5）；密码单词 L3 = L4（都是 3 张差一个字母的图）。
→ 建议：十格灯按级加东西，比如 L3 十格框、L4 灯的排列打乱 / 一行 5 盏换成散点、L5 两个数字（"三，五"：先点三盏再加到五盏）或者去掉十格框只给一排；补元音 L4 起干扰元音里固定放"长得像的字"对应的词（p_n：pen / pan / pin 全在词表里才有歧义，需要配图限制）或 L5 去掉图只给词和录音；押韵 L5 五张图；全家福 L5 两个"他的"（"他的爸爸的车"太长，不如"她的弟弟"加上 她）；密码单词 L4 就四张图。

**[中等] W3R1-02 只剩一个字没过关时，一整局 5 题全考这个字；十格灯 / 全家福 / 照着做连题目都完全一样（委托方："重复的关卡没有意义"）**
证据：`rv_need.log`：把岛上 4 个字设成两局过关、1 个字一局，再玩一局——`thor3:quiz`（八）：八 八 八 八 八，**5 题只有 1 个不同的题目键**；`hulk3:quiz`（三）：三 三 三 三 三；`panther3:quiz`（蓝）：蓝 ×5；`widow3:quiz`（哥）：哥哥 ×5；`hawk3:quiz`（看）：看 ×5；`hulk3:find`（四）：四 ×5；`widow3:find`（弟）：弟 ×5；对照 `peppa:find`（目）：目 ×5（第一世界早已如此）。真实路径见 `rv_prog.log` P3：雷神认字第 5 题答错（六），下一局挑战是"六、再来一个(六)、六、六、六"——第一局认字只要最后两题错一个，这个字就只有 1 次过关，后面的挑战整局都是它。原因：`G.needPass` 在 `Session.start` 算一次（`W.chars.filter(k => !Mem.passed(k))`），整局不更新；`FindBase.gen`、`W3X.pick`、`QFamily.gen` 都是 `need.length ? PICK(G, 'need', need) : ...`，need 只有一个元素时袋子永远吐它；十格灯的题目键只有 `[answer]`，`genQ` 60 次都撞同一个键，最后原题再出。
→ 建议：每轮重算 `needPass`（`Mem.answer` 答对后 `pass` 已经更新），或者 need 里的字这一局只优先出一次、之后回到全岛的袋子；十格灯的键加上灯的排列或题型，保证一局五道题不同。

**[中等] W3R1-03 8 种新玩法的"第二级提示"只是主持人挥手，没有任何帮助，星却扣掉了（委托方："只把问题再说一遍的提示不算"）**
证据：`rv_play.log` C 段（提示时钟压缩）：押韵、补元音、首字母、我看见、数一数、涂颜色、全家福、照着做 8 个游戏在 hint2 之后答对星都是 0 → 0，而记录到的话只有 hint1 / hint3 把问题再说一遍；`rv_rt.log` RT9（真实时长）：全家福 hint2 在 13.5 s、押韵 14.6 s、涂颜色 12.0 s、数一数 11.5 s，之后 2.5 s 内没说一句话、画面没变（`shots/rt_hint2_*.png`），`assists = ['hint1','hint2']`，答对 0 星。代码：`GameBase.gestureHint() {}` 是空的，这 8 个游戏没有自己的 `gestureHint`；`Hints.tick` 到 10 s 先 `mark(st, 'hint2')`，`helped()` 只看这个标记。认字 5 种有图（出答案的图，扣星合理），十格灯有"一盏一盏点亮"，密码单词是软提示。前两个世界的 13 个挑战同样没有 `gestureHint`，三轮评审没有抓到；但这一期把它扩到 8 个新游戏，其中全家福、涂颜色、照着做、数一数是看字 / 看图想的题，10 秒正是孩子在读。
→ 建议：二选一。(a) 给这 8 个游戏真的第二级帮助：看字卡的题就把卡读出来（和点卡同一个后果，顺理成章扣星）；数一数把东西逐个跳一遍数出声；押韵 / 补元音 / 首字母 / 我看见把目标词或字母再放慢说一遍、让选项依次跳；(b) 没有 `gestureHint` 的游戏 hint2 不算帮助（`helped` 只在游戏真给了帮助时才成立）。

**[轻微] W3R1-04 涂颜色的白桶不好认；《红车白云》第 6 页"花是红的"是一朵粉花**
证据：`shots/crop_pots_L4.png`、`L_panther3_quiz_L4.png`、`P_panther3_quiz_L4.png`：白色颜料是米白桶口上一道白色带子，放在白卡片里，正常大小下几乎看不出"这桶有颜色"；放大后才分得清。`shots/sheet_books_b3_b4.png` 最后一格：`flower` 原图是粉紫色，`hue-rotate(-24deg) saturate(1.8)` 之后是洋红 / 粉，不是红车、红草莓那种红，孩子读"红"看到粉。
→ 建议：白桶换成深色桶身或桶里画一层白漆、桶边加灰影；"花是红的"换一个本来就是红色的东西（草莓已经是红的图：改句子，或者给 `flower` 做一张红花）。

**[轻微] W3R1-05 岛面板的游戏图标：特工基地"认字"看不见，几个"写字"图标红字压在晚霞 / 深色上**
证据：`shots/crop_panel_widow3_icons.png`：第一个图标是黑色的"爸"压在深蓝控制室背景上，几乎只剩一个圆；写字图标是红"妈"压深蓝，勉强。`crop_panel_hulk3_icons.png`：写字图标红"一"压在橙色晚霞上，看不出是一横。前两个世界背景亮、字能看见，这一期有 5 张深色 / 暖色背景。
→ 建议：图标的字加一个白色圆底或白描边（`Glyph` 加 `stroke`），和"三 + 三个苹果"那个图标一样放一块浅底。

**[轻微] W3R1-06 字宝盒里点亮的只认读字，一点就进整字书写练习**
证据：`rv_prog.log` P8：三 两局过关后在字宝盒点亮（`learned` 为真），点它 → `Practice.start` → `practice:zh` 写字练习（`kind: write, practice: true`）。对 三 无妨，但 喝（12 画）、蓝（13 画）、绿、黄、哥、看、爸、姐、是 都是方案说"只认读"的字，宝盒里却是整字带示范的书写。不计星，不违反铁则，但和"只认读"矛盾；V2R3-01 当时就建议过"宝盒里的练习可以是认读卡"。另外卡片英文"little brother"超出卡宽被截成"little brothe"（`shots/L_book_zh_end.png`）。
→ 建议：`NOWRITE` 的字在宝盒里点开用认读卡（听一听、找一找）或者只听读音；英文标签缩小或换行。

**[轻微] W3R1-07 跳石头从第一局起就"颜色骗人"**
证据：认字在彩虹海从 L2 起（`rv_data.log`），`PlayLeap.targets` 在 `lv >= 2` 就把牌子涂成永远不是自己的颜色（`shots/L_panther3_find_L2.png`：黄在白牌、绿在蓝牌、蓝在黄牌）。孩子刚通过"字从画里来"认识 红 = 红草莓，紧接着第一道题就要在绿牌子上找 红。Stroop 是这个玩法的卖点，但放在第一次接触时，是先教"颜色"再立刻说"别信颜色"。
→ 建议：第一局（L2）牌子不涂色或涂成自己的颜色，L3 起再骗人。

**[轻微] W3R1-08 甩锤子时锤子不跟手；甩的方向容差 35°，5 朵云时相邻只差 37.5°**
证据：`PlayHammer.targets` 只注册 `flick`，没有 `drag`，手指按住锤子拖的时候锤子纹丝不动，松手才飞（`rv_rt.log` RT3 真实鼠标：25 px 不算、朝两朵云中间不算、点锤子 / 点云只说"把锤子甩出去"，偏 20° 的 60 px 甩中对的云，都对）。5 朵云在 150° 扇面里相邻 37.5°，取最近的那朵，所以判定没问题；但对 4 岁孩子，按住不动的锤子是最弱的"可以甩"暗示。
→ 建议：按住时锤子跟着手指走（像手电筒那样 `drag`），松手按方向飞。

**[轻微] W3R1-09 几处图的判断**
- 哥 = 大娃：全家福的"哥哥"照片是爷爷、大娃、七娃，和猪一家不是一家人；大娃和七娃只差颜色，靠认识葫芦娃才知道谁是哥哥（`shots/L_widow3_quiz_L3.png`）。委托方原图里没有现成的哥哥，这是个可以接受的选择，但家长最好知道。

- 书架上《十本书》的封面是第 1 页"我有一本书"，书只有拇指大（`crop_shelf_b3.png`）。
