## 中等偏轻

**W3R2-01 两次手势失败后的"重教"白送答案的图，星照给** → 改了，选择"重教只教手势"。

- 两次没甩出去、没拖到地方之后，重教只演示怎么玩：
  - 要拖、要甩的东西依次跳一下（装书包的字卡、浇花的水壶、送能量的能量块）；
  - 甩锤子：锤子往上抛一下；
  - 手电筒：光把整个房间扫一遍，每张卡都一样。
- 重教不再调出答案的图（`FindBase.gestureHint(st, reteach)`），所以它不是帮助，不扣星。真的第二级提示（10 秒，出图）照旧扣星。
- **为什么不选"重教也扣星"**：孩子手势没做对，不等于不认识字。重教既然不给答案，就不该拿走他自己认对的那颗星。
- 验收（`test_w3new` 14）：
  - 用真鼠标在甩锤子上轻轻拨两下（15 px）；
  - 装书包、手电筒各拖到空处两次；
  - 结果：都有 `reteach`、题目卡上没有图、不算帮助；接着答对有星。

- **只剩两个字没过关**：`needPick` 的兜底不再选已经考过两次的未过关字。
