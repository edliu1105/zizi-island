## 1. 总体结论

方案落实得很全：七箱位、到期才升、错题降两箱、复习 1/2/3 道按到期数浮动、不凑数、插旗要"两局都对"、钥匙 → 固定卡序 36 张、故事书、停船、写字两级兜底、家长面板的四种状态 / 保持率 / 只往下调的考一考 / 早期信号 / 报告 / 导出恢复 / 红点、彩虹海和五个"新岛快来啦"，逐条对着代码和运行结果查过都在，而且边界处理得细（复习题答错不再补复习题、同一天只升一箱、7 天以上没来钥匙直接送、箱位只认自己第一次就对）。句子岛的画面干净，"字从句里来"的节奏好（图 → 整句 → 要教的字亮起来读一遍 → 英文 → 题目，11.8 s 到可答），读一读的 16 道题三张图确实只有一张对，故事书 12 页每页不超过 8 个已学的字。既有测试 core 102、r1 15、r2 9、r3 10、v2 19、pointer 80 全过。

但有三件事会让孩子和家长在第一周就撞上：

1. **读一读点字没有反应**（真实手指点上去什么都不发生，`.item` 行吃掉了 pointer-events）。这是读一读唯一的求助路径，没有它，读不出句子的孩子只能三选一乱猜。`test_layout` 其实报了（12 处 covered 100%），但发布在跑套件之前。
2. **四个 ✓ 之后常常没有旗子，而且一个字都不说**。按真实起始难度把一个岛的四个游戏各玩一局、全答对，第一世界除佩奇岛以外每个岛只有约三分之一的概率当场插旗，两个句子岛 6 次里 0 次。孩子听到"集满啦！玩得真开心！"回到地图，旗没有、云没开、没有一句话解释。"再玩一局插旗子！"只在孩子自己去点面板上的旗位时才说。
3. **旧存档迁移后，复习系统是空的**。孩子已经写过的 40 多个字全部变成"见过"（第 0 箱），永远不到期：钥匙局直接送钥匙，复习题一道都不出，家长"考一考"弹出"还没有学过的字可以考"。真正玩着 W1 的那个孩子，正是这个状态。

三件都不难修，但第一件是功能坏了、第二件是主循环卡住不说话、第三件让 v2 最重要的承诺（按遗忘规律复习、看得见）在上线后好几天里是空转。所以这一轮不能批。

## 2. 问题（按严重程度）

**[重要] V2R1-01 读一读里点字听音，真实手指点不到**
证据：`rv_tap3.py`，横竖屏各一遍，按下 90 ms 松开：第一世界的泥坑卡、字母排队卡、读一读的图片卡、补句子的字卡都正常提交；读一读的字格 `ch0` 点下去 `peeked` 仍是 false、没有任何语音，`document.elementFromPoint` 在字格中心取到的是 `#stage`。`tests/logs/rv_layout.txt`：`s1:quiz` L1–L3 共 12 处 `covered 100%`，整套 layout 测试 FAIL。原因：句子行用 `ZX.thing(st, 10, 10, 7, '')` 建，`cls || 'item'` 让它带上 `.item`，`head.html` 第 230 行 `.item:not(.tgt){pointer-events:none}` 对整行生效，字格虽然有 `cursor:pointer` 和 `K.reg`，手指事件穿过去落到舞台上。`test_v2` V-06 用的是 `__gesture('tap',{id})`，绕过了命中测试，所以没发现。
→ 建议：给句子行加 `.tgt`（或字格 `pointer-events:auto`），让 `test_layout` 回到绿色后再发；读一读的点字是方案 A.3 的核心，补一条真实指针测试。

**[重要] V2R1-02 四个 ✓ 之后没有旗子时，孩子得不到任何解释**
证据：`rv_rules3.log` I 组。新存档、真实起始难度、每个游戏各一局、全部答对（这是最顺利的孩子），当场插旗的次数：佩奇 6/6（翻翻乐考字），Bluey 2/6、葫芦山 2/6、农场 2/6、花果山 2/6、光之国 2/6、汽车人 2/6（挑战只考字母，字只在认字和写字里各出一轮，总有一个字只过了一局），小学堂 2/6、夜空 2/6、百花园 1/6，**钢铁侠大厦 0/6、美国队长岛 0/6**（5 个字、补句子 3–4 个位置、读一读不计任何字的过关）。真实时长（`rt/tick4_*.png`，`rv_realtime.json` tick4）：Bluey 第四个 ✓ 落下 → "集满啦！→ 玩得真开心！" → 回地图 → 葫芦山仍盖着云、没有旗、没有话；面板只是让第一个游戏发光。`rv_rules.log` P：面板打开只说"佩奇来啦！"，"再玩一局插旗子！"要孩子自己点旗位（`app.js:716`）才说。4 岁孩子不会去点一个灰的虚线框。
→ 建议：第四个 ✓ 之后 `Prog.islandDone` 为假时，回地图就说"再玩一局插旗子！"并指向那个岛（`Session.finish` 里 `newGame` 为空、`gamesDone` 为真、`flagged` 为假这一分支）；同时让最后一局把 `needPass` 的字优先级提到 100%，读一读也给句子里本岛的字记一次过关（`QReadS.itemOf` 现在返回 null）；句子岛 5 个字、两个游戏考字，按现在的规则几乎必然要多玩一局。

**[重要] V2R1-03 旧存档迁移后，复习、钥匙、考一考全部为空**
证据：`rv_rules.log` B，`rv_rules.json` migrate：模拟真实情况（W1 前 5 岛插旗、光之国玩到一半，42 个写过的字和字母）→ `Store.validate` 后 42 个都是 `seen`（第 0 箱）、`Mem.due()` = 0、考一考的候选池 = 0（`ParentV2.check` 只收 `b > 0`，直接 toast"还没有学过的字可以考"）；第一天的钥匙 `Keys.start()` 不出题直接送卡。第 0 箱的字只有再被某个游戏偶然问到（L4 混旧字、翻翻乐）答对后才进第 1 箱，`Mem.answer` 里 `b === 0` 答错什么也不记。PLAN 第 11 条说"旧记录迁为见过"是为了不把它们算成"认识"，没说要把它们排除在复习之外。
→ 建议：迁移时写过的字进第 1 箱、`due` = 今天（或第 2 箱 due 明天），这样第一天的钥匙局就是"找回老朋友"、考一考有字可考、报告里有数；或者第 0 箱的字在没有到期字时也进钥匙局。

**[中等] V2R1-04 读一读、补句子的第二级提示什么都不给，却照样扣星**
证据：真实时长（`rv_realtime.json` read_idle，`rt/read_idle_6s/11s/16s.png`）：读一读题目出现后不动，5 s 重说"读一读！"，10 s 第二级提示 = 句子行跳一下（`QReadS.gestureHint` 只 `K.hop`），15 s 鼓励；此时答对 → 星 0。补句子的第二级提示是把句子再说一遍（`QFill.gestureHint`），和免费的喇叭按钮一样。方案第 12 条扣星的前提是"出图、示范这一笔"这种真帮助；默读一句 5 个字的句子，4 岁孩子 10 秒很正常。
→ 建议：这两个游戏的第二级提示要么给真帮助（读一读把句子读出来，等同点字，扣星一致），要么不算 `hint2`；或者读一读的阶梯放慢到 10/20/30 s。

**[中等] V2R1-05 卡册 36 张发完后，钥匙局做完什么都没有**
证据：`rv_rules.log` G：`album.n = 36`、有钥匙 → `Keys.start()` → 钥匙记作已领、`Keys.turn` 直接 return，没有翻卡、没有声音、没有卡册。按一天一把钥匙加 9 面旗，大约第 4–5 周就到。方案说"以后每个世界包带 30 张"，但二期之前这段时间孩子每天做完"找回老朋友"得到的是沉默。
→ 建议：卡发完时至少打开卡册说"我的英雄卡！"，或循环回第一张加金边；最好在二期前先补一包。

**[中等] V2R1-06 "来"没有字形数据，句子里是一个看不见的空格**

## 3. 抽查了什么

**方案逐条**（`rv_rules.log`、`rv_rules2.log`、`rv_rules3.log`）：
- 箱位：新字首次自己答对 → 第 1 箱、明天；到期答对 → 升一箱（1、3、7、14、30、60、120 天）；提前答对不动；同一天不升两次；答错或第二级提示后答对 → 降两箱、明天（`test_v2` V-02 复核）。
- 复习混入：到期 0 → 0 道，≤3 → 1 道（第 2 题），更多 → 2 道（第 2、4 题），刹车 → 3 道（第 2、4、5 题）；候选只取到期且不是本岛的字，没有凑数（`rv_rules.json` brake、`Review.plan/slot`）。复习的三种形态都看到了：认字游戏里用本岛玩法考旧字（`L_review_find_form_huluwa.png`），写字游戏里写老朋友 人（`L_review_write_ultra.png`），其他游戏里出卡片（字 `L_review_card_char_in_bluey_quiz.png`、字母 `L_review_card_letter_in_huluwa_find.png`），复习卡答对照常给星（O：一局 5 星）。
- 漏答队列：见 V2R1-08。
- 插旗：四个 ✓ 不够、每个字两局各一次自己答对才行（`test_v2` V-04）；旧旗保留（`pok`）；但自然流程里的插旗率见 V2R1-02。
- 句子岛：补句子 300 题全部"句子属于那个字、空在对的位置、选项里答案只出现一次"，L3 起 4 个选项都凑得齐（`fill_s1_L3`）；"字从句里来"真实时长看了 我、你 两次（`rt/meet_a–d.png`：图 → 整句 → 我 亮起 → "我，我们的我！" → "I"）。
