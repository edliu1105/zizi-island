# 用户体验评审（字字岛 · 神笔海第 2 轮 + 两个新岛 + 写字多样化，Fable 5.1 · high）

你是独立评审。对象是 `index.html`（字字岛）：给 4 岁中文孩子（住在美国）的 iPad 认字、写字、学英文 PWA。

**这是神笔海的第 2 轮。** 第 1 轮（`docs/REVIEW-W4R1N.md`，8/10）提了 W4R1N-01 到 10。开发方的修改都已上线（提交 89d67cc）。同一次上线还有两件委托方新提的事：
1. **每个世界都要有全部 9 个角色家族**（佩奇、Bluey、睡衣小英雄、汪汪队、葫芦娃、西游记、复仇者、变形金刚、奥特曼）：神笔海加了 ⑧ 复仇者·英雄训练场（好力出王高）和 ⑨ 变形金刚·汽车人工厂（变能工厂路），设计 `docs/W4-DESIGN.md` §12。
2. **写字不要永远一个样子**（委托方原话：例如先写"人"、让他补一横知道是"大"；写个"日"、让他补一笔变成"目"）：所有世界的写字现在有 7 种方式轮换——第一次见面描红；之后轮换 加一笔变新字、部件拼字、像不像、补缺笔、你一笔我一笔、描仿写渐隐。规则见 `docs/WRITE-MODES.md`；"A 加几笔 = B"的配对表由 `tools/write_pairs.py` 对着笔画数据逐对验证。

**请先逐条核对 W4R1N-01 到 10（已修好 / 部分 / 没修好）**，再看两个新岛和写字多样化，最后全面看一遍。

## 铁则
- 星星只给自己第一次就答对的题；答错的那道没有星，直接下一题；第二级提示之后答对不给星。
- 每道选择题 5 个选项（只有 2–3 种答案的改一题两问）；答错后讲解（蓝圈他选的、金圈对的，2–5 秒，点一下跳过；家长可设关 / 自动 / 一步一步）；教一教。
- 不说"错"、没有红叉、没有失败音；每句语音 ≤ 8 字且有录音；点按目标 ≥ 88 px；家长功能在长按齿轮里；不用第三方库；委托方的角色原图不能重画。
- 笔顺：汉字按 GF 0023-2020（`tests/data/stroke_order.json`），字母按 Zaner-Bloser。**写字多样化不能教错笔顺**：例如"人加一横变成大"，大的笔顺是先横，孩子要在横的位置写它。
- 每个世界的玩法都要新，不能和别的世界重复。

## 请重点检查
1. 第 1 轮 10 条的修改。
2. ⑧ ⑨ 两个岛：6 种新玩法 + 两个岛的写字；10 个新字的选择、配图、笔顺；只出认识的字；乱点；L1–L5；讲解；开岛（插过 ⑦ 旗的存档开 ⑧、"神笔海有新岛！"、大合影加演一次）；9 个岛的地图在 8 种尺寸不挡。
3. 写字多样化：7 种方式对 4 岁孩子清不清楚、是不是真的更有意思、能不能帮他记住；"变"的那一下看不看得懂；笔顺在每种方式里都对、提前写后面的笔不被接受；真实手指 / 指针在 3 种尺寸能写；轮换是否合理（第一次一定描红）；配对表里有没有"不真的是加几笔"的；所有世界、宝盒、复习、教一教、一步一步都正常。
4. 回归：前三个世界、复习、星星规则、讲解设置、离线、首屏（`index.html` 预算 640 KB / 180 KB gzip，现在约 150 KB）。

用 `tests/harness.py` 和 Playwright 自己操作、截图（`window.__go(island, game, level, opt)`、`window.__q`、`gesture()`；可直接改 `Store.s`；`tests/fixtures/` 有几份旧存档）。已有测试：`tests/test_w4.py`、`tests/test_w4open.py`、`tests/test_writemodes.py`、`tests/test_strokes.py`、`tests/test_pointer.py`、`tests/test_options.py`、`bash tests/run_all.sh <tag>`。可以跑，但要自己验证。截图和数据放 `tests/logs/`，不要改 app 的代码。**非交互模式**：所有命令前台运行（长的分段或加 timeout），结束前一定写好报告。
