## 3. 问题（按严重程度）

### 问题 1（低）前两题都答错时连听两遍"再来一个！"

- **证据**：`tests/logs/ox2/dup_again.json`（真实速度，1180×820）。跳泥坑 L2 第 1 题错 → "下一题！"；第 2 题错 → 收尾"再来一个！"（12.55–13.17 s），紧接着第 3 题是第 1 题错过的那个字回来的复习卡，它的开场白也是"再来一个！"（13.27–13.89 s），然后才是"哪个是目？"。点气球 L2 同样复现。两句是同一条录音，中间只隔 0.1 秒，孩子听到的是"再来一个！再来一个！"。
- **为什么会这样**：`NEXTQ` 的第 3 项是"再来一个！"（第 1 轮回应里说的"再来一题！""下一题！""再来一个！"轮换），而 `v2.js` 里错过的字回来那张卡的 `missQ` 提示本来就是"再来一个！"（V2 的设计）。一局里第 1 题错、第 2 题也错，正好是"第 2 次错的收尾语"接"第 1 题错字回来的卡"，两者必然相邻。
- **建议**：收尾轮换里去掉"再来一个！"，只留"再来一题！""下一题！"（或改成别的已录句子，如"看下一题！"要新录音）；或者 `ReviewQ.present` 在上一句就是"再来一个！"时不再重复。只动 `app.js` 的 `NEXTQ` 或 `v2.js` 一行。

### 观察（不算问题，记录给开发）

- **录音库**：`assets/voice/v/` 里有 11 个 mp3（01b0be60、0228ea07、32d0bd95、49b73760、6dab5415、725e2e97、7c46bfea、9d919e49、c7b6be5c、d17a4be9、f3b4a337）不在 `bank.json` 里但被 git 跟踪、也在 `sw.js` 的离线清单里——是没人用的旧录音，白占离线缓存约 50 KB，不影响功能。
