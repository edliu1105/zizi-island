# R1 回应（Fable 5.1 · high，7/10）

评审确认了几件事：写字引擎对 4 岁孩子看得懂、写得出；"字活过来"好看；530 句录音一句不缺；不操作 60 秒没有任何代做；答错换新题、不给星。评审也指出，几处内容正确性的问题会让孩子"选对了也被判错"或"只能猜"。10 个问题全部修好，每一项都加了检查（`tests/test_r1.py`，15 项）。

| # | 问题 | 处理 |
|---|---|---|
| 1 严重 | "哪个写对了"会出两张一样的卡（B 上下翻还是 B，S 转 180° 还是 S） | 每个错项都和正确的、和其他错项逐点比较（点距超过字形的 8% 才算"看得出不一样"），不够不一样的变换不出。另外两类字形整个不出：<br>• 翻过来会变成另一个真字母的（P→b d q、M→W、u→n），因为孩子可能把它当成写对了；<br>• 翻过来会变成另一个真字的（上/下）。<br>题目先说是哪一个（英文读字母名，汉字读"手，小手的手！"），任务卡上有它的图。检查：五个难度各 1000 题，没有一题出现两张相似的卡。 |
| 2 中 | "缺了一笔"的错项常和答案同名同形（两个撇） | 错项的笔画名必须和答案不同、彼此也不同，也不再用同一个字的另一笔。每张卡是一个小田字格，笔画画在它在字里的真实位置、真实大小，长短和位置都看得出来。答错时说出点的是哪种笔画（"这是横"）。检查：五个难度共 1000 题，没有重名，没有同字。 |
| 3 中 | 禾、米、休的最后一笔是捺，小的第二笔是撇 | 已改。另加一项检查：56 个字的每一笔，横、竖、撇、捺、点、提都要和它中线的走向一致（撇往左下，捺往右下且够长，点短而向下，横平，竖直）。 |
| 4 中 | 认字 L1 和 L2 一样；L3 以后卡住再久也不给图 | L1 任务卡上有那样东西的图片；从 L2 起只听，卡住 10 秒（第二级提示）时图片出现在任务卡上。这是把题目说完整，不是给答案。检查：L1 一开始就有图，L2、L4 一开始没有，提示后出现。 |
| 5 中 | "读单词"的字母叠在一起 | 一个单词画成一张图：字母站在同一条基线上，各按自己的宽度排开，互不接触。 |
| 6 中 | 横屏岛面板主持人的头被切 | 面板上的东西（主持人、岛、4 个游戏、小星星、这个岛的字）按屏幕高度整体缩放、上下居中。检查：4 种尺寸 × 3 个岛，全部在屏幕内。 |
| 7 轻 | 翻转的字形掉到卡片下半截 | 卡片上的字形按自身的范围居中，翻转、旋转都绕字形自己的中心。检查：正的和翻的都在卡片正中（偏差为 0）。 |
| 8 轻 | 字宝盒封面少了世界进度条 | 封面加了两条：晨光海、星光海各 7 格，一格一个岛，按学会的字和字母慢慢填满，填满一格就描边。 |
| 9 轻 | "字从画里来"是淡入，不是一笔一笔写 | 改成毛笔在图片上按笔顺一笔一笔写出来（和写字示范同一支毛笔、同一种墨迹）。字母第一次出现时也有这一幕：先出现苹果，再写出 A。 |
| 10 轻 | 缺的那一笔用虚线描了出来，等于给了答案 | 只在 L1–L2 描出来当作脚手架，L3 起只留空白。 |

验证：`tests/test_r1.py`（15 项）、`test_core`（102 项）、`test_pointer`（80 项）、`test_layout`（4 种尺寸）、`test_voiceflow`（真实时长）全部重跑。重新截图看过：哪个写对了、缺了一笔、岛面板、字宝盒、读单词。
