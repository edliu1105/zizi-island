# 用户体验评审（字字岛 · 新世界「神笔海」· 第 1 轮，Fable 5.1 · high）

你是独立评审。对象是 `index.html`（字字岛）：给 4 岁中文孩子（住在美国）的 iPad 认字、写字、学英文 PWA。已有三个世界：晨光海、星光海（含句子岛）、彩虹海。

**这次评审的是第四个世界「神笔海」**（`docs/W4-DESIGN.md`，`docs/DESIGN.md`、`docs/DELIVERY.md` 里的神笔海一节）：7 个岛、35 个新字（天地金土川 / 耳足头牙心 / 坐站飞说听 / 对雪虫鱼草 / 多少开关去 / 左右中前后 / 爷奶妹女子），每岛写 2 个字加一个老朋友，21 种新玩法（认字、英文、挑战各 7），另有读一读句子、两字词、书、韵文卷轴、古诗。委托方要求"照着学而思大纲做"；研究发现学而思美国没有中文课，按委托方的指示用 2024 统编版一年级上册的识字顺序、学而思小猴语文启蒙级的课型补齐（设计文档 §1.5 和附录 C 有出处）。**已先上线**（提交 41be1f6，测试文件 11c2b84），这是上线后的评审。

**开启**：完成晨光海就开（存档里一直开着）；每片海的地图上有一支发光的神笔，第一次进地图飞过去一次（"新世界开啦！"），月亮门回到来的那片海；家长面板有"现在就去神笔海"。委托方刚因为找不到点点岛的新世界吃过苦头，开启和找到入口这件事请特别检查。

## 铁则

- 星星只给自己第一次就答对的题；答错的那道没有星，直接下一题；第二级提示之后答对不给星。
- 每道选择题 5 个选项（只有 2–3 种答案的改一题两问）；答错后讲解（蓝圈他选的、金圈对的，2–5 秒，点一下跳过；家长可设关 / 自动 / 一步一步）；教一教。
- 不说"错"、没有红叉、没有失败音；每句语音 ≤ 8 字且有录音；点按目标 ≥ 88 px；家长功能在长按齿轮里；不用第三方库；委托方的角色原图不能重画。
- 笔顺：汉字按 GF 0023-2020（`tests/data/stroke_order.json`；左、右是先横后撇），字母按 Zaner-Bloser。
- 每个世界的玩法都要新，不能和别的世界重复（设计文档 §7 有对照表和"相近但保留"的几处）。

## 请重点检查

1. **开启与入口**：各种存档（只完成晨光海、在星光海、在彩虹海、新玩家）都能马上找到并进入神笔海；神笔在每片海都看得见、不挡东西；第一次飞过去只一次；月亮门回去；什么都不锁、不丢（`tests/test_w4open.py`）。
2. **21 种新玩法**：对 4 岁孩子清不清楚、好不好玩；L1–L5 是否每级难一步；有没有两个对的答案；乱点能不能过；讲解（一步一步每一步）是否让他看懂；只出他认识的字。
3. **识字教学**：35 个字的选择和顺序、配图（不能是答案、不能吓人）、写字（笔顺、演示、判定）、读一读和书、韵文卷轴。
4. **英文**：词族、高频词、短句，配图对不对（例如 in / on the box）。
5. **不重复**：和前三个世界比。
6. **画面**：横屏 1180×820、竖屏 820×1180、1024×768；新图质量。
7. **回归**：前三个世界、复习、星星规则、讲解设置、教一教、书写、离线、首屏（`index.html` 预算 640 KB / 180 KB gzip）。

## 方法

- 用 `tests/harness.py` 和 Playwright 自己操作、截图。测试钩子：`window.__go(island, game, level, opt)`、`window.__q`、`gesture()`；可直接改 `Store.s` 造存档（`tests/fixtures/` 有几份）。
- 已有测试：`tests/test_w4.py`（`W4_ONLY=…`）、`tests/test_w4open.py`、`tests/test_options.py`、`tests/test_layout.py`、`tests/test_strokes.py`、`bash tests/run_all.sh <tag>`。可以跑，但要自己验证。
- 截图和数据放 `tests/logs/`。不要改 app 的代码。
- **非交互模式**：所有命令前台运行（长的分段或加 timeout），结束前一定写好报告。
