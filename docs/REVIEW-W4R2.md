## 1. 总体结论

这一版可以上线。第 1 轮的 10 条全部修好（逐条见第 2 节）；两个新岛的 6 种玩法在 1180×820、820×1180、1024×768 三种尺寸、L1–L5 都跑通，答错讲解在真速下 2.6–5.0 秒、蓝圈在他选的、金圈在对的，第二级提示真的帮忙，9 个岛的地图在 5 种尺寸目检、8 种尺寸实测都不挡；老存档插过 ⑦ 旗开机开 ⑧、别的海上的神笔说一次"神笔海有新岛！"、看过大结局的插满 ⑧⑨ 加演一次（32 人合影）都对。铁则没有一条被破坏：星星只给第一次答对、答错不说"错"没有红叉、每题 5 个选项或一题两问、点按目标 ≥ 88 px、每句话有录音（新岛两次整跑 0 缺）、笔顺按 GF 0023-2020、家长功能在齿轮后、没有第三方库、角色原图没重画。

**写字多样化是这次最大的改动，做得好。** 7 种写法我在真速下逐个看过：第一次写"好"先演"女 + 子 = 好"（女用自己的字形滑到好的左边，子亮橙色，配音"女加子变成好！"），再"看我写一遍"描红；之后"加一笔"（二 → 工：毛笔写上横，他写竖，毛笔写下横）、"部件拼字"、"像不像"（写完"目比日多一横"亮起来）、"补缺笔"、"你一笔我一笔"、"描仿写"三遍轮换。**笔顺在每种写法里都对**：新加的笔在它该出现的那一拍写，前后的笔由毛笔接着写；他提前写后面的笔（我在 L1 和 L5 各试了一次：工先写下横）不收，说"先写这一笔"，然后照常写完、这题没有星。40 对"加一笔"、12 个"部件"由 `tools/write_pairs.py` 对着笔画数据逐对证明（我重跑：grow 40, part 12, NOT TRUE []），表里没有"不真的是加几笔"的；"小 → 少"按说明排除了。

只找到**一处中等问题**：⑧-1「句子里圈字」的出题逻辑先按级别过滤句子、再从"有这种句子的字"里挑字，结果 L3 和 L5 只会考 2–3 个字、各只有 1–3 句固定的句子（"高"在 L3–L5 永远不出现，"力"在 L5 永远不出现）；孩子很快记住"王在第二格"。这是出题逻辑的小改动，不阻塞上线。其余是低风险：排故事 L1 的"开门 / 出门"两张提示图互为镜像、拍节拍里 bug 和 insect 共用一张图、几句句子用了"女子"这个词、一句英文句子倒过来也能读通。

按评分规则（9 分及以上通过）：**9 分，通过**；请在下一包里顺手修掉 W4R2-01。

## 3. 问题（按严重程度）

### 中

**W4R2-01 · ⑧-1「句子里圈字」L3 / L5 只考两三个字、每个字只有一两句固定的句子；"高"在 L3–L5 永远不出题**

- 证据：`src/w4/avengers4.js:43` `for (const t of TIERS[lv]) { const pool = mine.filter(k => cands(k, t).length); if (pool.length) { X = W4X.pick(G, pool); ... break; } }`——先按级别的第一档条件过滤句子，再只从"有这种句子的字"里挑 X；只要有一个字满足第一档，别的字就永远轮不到。L3 的第一档要"句子里有 X 的形近字且 ≤ 6 字"，L5 要"≥ 7 字、X 在词里、有形近字"。按 `SENT8` 和 `LOOK4` 算（假设孩子认识全部字，`tests/logs/rev2_check_know.txt` 和下表）：
  | 字 | L1 可用句 | L3 可用句 | L5 可用句 |
  |---|---|---|---|
  | 王 | 王说：开大门！ | 王去土山上 / 王有三头牛 / 王坐在土地上 | 大王出门，去土山上 |
  | 出 | 小马出门了 / 小草出土了 | 日出，山上白了 / 王出门，去山中 | 爷爷出门去山上 / 妹妹出门去山上 |
  | 好 | 天好大，山高 / 大牛好有力 | **无** | 女子说：你好，大王！ |
  | 力 | 大牛好有力 | 九头牛好有力 | **无** |
  | 高 | 3 句 | **无**（`LOOK4` 没给高定形近字） | **无** |
  实测（`rev2/dump_questions.json`、`rev2_shots_games.txt`）：L3 连续 10 题只在"王去土山上 / 王出门，去山中"之间交替；L5 10 题只有"大王出门，去土山上 / 爷爷出门去山上 / 妹妹出门去山上"三句；只认识晨光海 + 神笔海字的存档一样（`dump_questions_w1w4.json`）。
- 为什么是问题：L3、L5 是这个岛认字的后半程。孩子第三题起就知道"王在第二格、出在第三格"，不用在句子里找；"高"和"力"在高级别根本见不到，复习也跟着少。40 句的库只用到了 6 句。
- 建议：先挑字（`W4X.pick` 在本岛全部字里挑，照旧优先没过关的），再给这个字找它能用的最高一档句子，没有就降一档（7–8 字、两行也算难）；给"高"补形近字（`LOOK4` 里加 高 → 口，口在 `HOLDS4` 已经和高分开）和两三句带形近字的句子（例如"高山口中有水""大口吃，长高高"）；给"力"补一句 ≥ 7 字带"九"的句子（"九头牛，好大力！"）。改完用 `dump` 看每级每个字至少 2 句。

### 低

**W4R2-02 · ⑧-4「故事排排队」L1 的"开门 / 出门"两张提示图互为镜像**

- 证据：`tools/content.py` STORY8 里 X开门 的图是 `door_open` 在右、人在左，X出门 是 `door_open` 在左、人在右（同一张门、同一个人、只是左右对调）；截图 `rev2/g_1180x820_avengers4_quiz_L1.png`、`rev2/ex_avengers4_quiz_L2_2.png`（奶奶开门 / 奶奶出门两格）。L1 的 5 个故事里 4 个是"X开门 / X出门 / X去…"。
- 问题：L1 是"照着图放"的那一级，4 岁孩子分不出"人在门左边"和"人在门右边"哪个是开门、哪个是出门，图没起到作用，只能靠读字（那就不是 L1 了）。
- 建议：开门用"手拉着门把、门半开"（`door` → `door_open` 两张并排也行），出门用"人已经在门外、背对着门走"（现成的 `walk`），两张图一看就不一样。

**W4R2-03 · ⑧-3「拍拍节拍」bug 和 insect 共用一张图，拍数不同**

- 证据：`BEATS8` 里 `('bug', 'insect', 'bug')`（1 拍）和 `('insect', 'insect', 'in-sect')`（2 拍）用同一张 `insect.png`。
- 问题：L3 起只念一遍、正常速度，孩子看着这张虫子图敲两下（他在彩虹海学的是 bug，不是 insect），会答错；两个词也可能在同一题的两张卡上出现、图一模一样。
- 建议：去掉 insect（bug 已经够用），或给 insect 另一张图（蚂蚁、甲虫）。

**W4R2-04 · `SENT8` 里把"女子"当一个词用**

- 证据：`('好', '女子去山上，好高！')`、`('好', '女子说：你好，大王！')`。
- 问题："女子"是书面语，4 岁孩子不说也听不懂；这两句恰好是"好"在 L4 / L5 能用的句子。
- 建议：改成"妹妹去山上，好高！""妹妹说：你好，大王！"（妹、妈、奶都是本世界的字，形近字"女 / 妈"可以留在别处）。

**W4R2-05 · ⑨-3 一句英文句子倒过来也能读通**

- 证据：`ESENT9` 的 `It is a big box.`——L3 起全小写，`is it a big box` 对一个 4 岁孩子来说和 `it is a big box` 一样顺口（句号固定在最后，设计说"不收调过来也通的句子"）。
- 建议：换成 `The box is big.` 或 `I see a big box.`。

**W4R2-06 · 写字多样化的两处小偏差（设计文档 vs 实现）**

- "像不像"文档说"两个字都要是他写过的"，代码 `WM.options` 的 `known()` 用 `learned()`，而只认读的字（王、出…）只要复习通过也算 known，所以写"土"时旁边可能出现他没写过的"王"卡（`src/wm.js:26,34`）。对孩子没坏处（王他认识），只是和文档不一致。
- "部件拼字"表里 `木 = 十 + 人`：笔画上成立（`write_pairs.py` 证明了），但"木里有个人"不是真正的部件关系，和"日 + 月 = 明""女 + 子 = 好"放在一起，孩子可能把它当真。建议从 `STROKE_FAMILIES['part']` 去掉这一对（"十加两笔变成木"在加一笔表里已有，够用）。
