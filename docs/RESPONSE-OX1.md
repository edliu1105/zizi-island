# 字字岛 · 对第 1 轮评审（OX1，9/10 APPROVE）的回应

- **问题 1（中）乱点仍能拿星，只是慢了** → 交给委托方决定。委托方先选了"一局里能猜的题错满 3 道，这一局的星不算"，随后撤回（孩子可能边学边错，答对的题还是该拿星）。星星规则保持原样：每道题自己第一次答对就有一颗星。防乱点靠 5 个选项和答错后的讲解。
- **问题 2（低）虚词的"它是什么"配图会被当成字义** → 改了。我 你 他 是 的 了 不 有 在 这 讲解时不再配场景图，改成把例句写出来、这个字标色（对的标金、他选的标蓝，例如"羊不大。"）；放不下不碰别的选项时只圈不配。认字卡、复习卡、钥匙局都一样。
- **问题 3（低）选项挨得近时金圈、蓝圈互相叠压** → 改了。圈每一边最多外扩到和邻居空隙的一半，没空间就画在边缘以内；蓝圈总在金圈上面；砸石头好几块对的只圈一块、其余描金边；合体字不再给整个算式加第二个圈。`test_options` 在 420 个游戏 × 级别里检查没有两个圈部分重叠（完全套住允许）。
- **问题 4（低）收尾语"再试一次！"** → 改成"再来一题！""下一题！""再来一个！"轮换；写字仍是"再写一个！"。点点岛同样改了。
- **问题 5（低）个别错误选项一眼就能排除** → 翻翻乐第一个岛 L1–L2 的第 5 张用形近字（日、牛、大），不用字母、不用含答案的字；全家福 L1 多出来的人用宾果（妹妹）、葫芦爷爷，葫芦家再加师父，都是委托方原图、都不是超级英雄，也都不带被问的五个称呼，所以 L1 仍比 L2 容易。
- **观察：缺了一笔的讲解没有话** → 选的那一笔放到字上它原来的位置时，主持人说"放不进去"。
- **观察：字母短横太挑剔** → 每个字母笔画（点除外）都用长笔画原有的 17% 格高宽容度，另加方向检查（直笔画要在 35° 以内），所以 I、E、F、H、A、T、t、f、J 的横偏 15% 能过、20% 不过；横写反、竖着划过横仍然不算；一笔写完的字母最后一段少写 20% 仍不算写完（截图 `tests/logs/strokes_shots/short_endings.png`：大多变成别的字母）。`test_strokes` 新加第 06 项。
- 另外：`tools/gen_sw_list.py` 只把 git 跟踪的文件放进离线预缓存，本地多出的文件不会让线上离线安装 404 失败。
